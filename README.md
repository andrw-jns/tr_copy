# TPMA review

The work in and around this repository are part of a rolling programme to review the types of potentially mitigable (TPMA) accounted for in the New Hospitals Programme (NHP) core demand and capacity model.

The main model repository can be found here: https://github.com/The-Strategy-Unit/nhp_model.

The current mitigator definitions upon which our review will revisit and update in certain cases can be found here: https://github.com/The-Strategy-Unit/nhp_data/tree/28e223627090c5ec49d54b2d4d0a8f34ea39be1a/src/nhp/data/raw_data/mitigators.

Link to the dev version of the book with access limited to project team: https://connect.strategyunitwm.nhs.uk/nhp_tpma_review_dev/.

Link to the live version of the book: https://connect.strategyunitwm.nhs.uk/nhp_tpma_review/.

For analysts conducting a TPMA review, please see [`analyst_guide.md`](https://github.com/The-Strategy-Unit/nhp_tpma_review/blob/main/analyst_guide.md).
